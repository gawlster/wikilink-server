# WikiLink Server

> This is the backend for WikiLink. It handles game generation, result validation, authentication, and data persistence. The frontend counterpart is available here: [wikilink-client](https://github.com/gawlster/wikilink-client).

- [Privacy Policy](https://github.com/gawlster/wikilink-privacy)
- [Available on the Chrome Web Store](https://chromewebstore.google.com/detail/wikilink/emkinglnjogipkbdaolejamloekkjboj)
- To provide feedback, report bugs, or suggest features, please fill out [this form](https://forms.gle/4xWNBD1PoE6n5qwz8)

## 🛠️ Development Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/gawlster/wikilink-server.git
   ```

2. Globally install Vercel CLI:
   ```bash
   npm i -g vercel
   ```

3. Start the dev server:
   ```bash
   vercel dev
   ```

> The first time you run this, Vercel will prompt you to log in and configure the project. Just follow the prompts. Environment variables are automatically pulled from Vercel.

## 🚀 Deploying to Production

Push your changes to the `main` branch.
